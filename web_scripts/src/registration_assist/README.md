# 履修手帖の時間割を学務に入力する

学務にログインし、「履修登録・登録状況照会」の時間割を表示します。アプリのメニューから「履修手帖の時間割を履修登録に入力」を開き、履修手帖が出力した `MBGREG1.` テキストを貼り付けます。プレビューで対象を確認し、「入力を開始」を押します。

アプリは「選択」「削除」を押しません。検索結果で科目を確認し、ご自身で「選択」を押してください。学務の優先度は初期値のままです。選択後は開講番号が時間割に表示されたことを確認し、「次の科目へ」を押すまで待ちます。

開講番号が時間割にあれば「登録済み」とします。集中講義など固定コマがない科目、学期が不明な科目、最初のコマに「追加」が出ない科目は手動登録です。プレビュー時点で別学期の表が表示されていなければ、開始後にその学期を開いた時点で確認します。セッションはアプリのメモリにのみ保持します。

入力補助が終わり、学務の時間割が表示されていれば「登録状況を履修手帖用にコピー」で申請中や許可の情報を履修手帖の「単位・要件」に渡せます。

## 学務画面の前提

大学の履修登録手順書に記載された表示と、既存の [履修照会の取り込み](../course_planner/README.md) の解析を基にした前提です。実際のページには接続せず、合成 HTML で検証しています。

- メイン文書の origin は `https://gakujo.iess.niigata-u.ac.jp`、パスは `/campusweb/` 配下の `campussquare.do` です。起点の `_flowId=RSW0001000-flow`、または Spring Web Flow の `_flowExecutionKey=e…s…` と登録画面固有の見出しを確認します。見出しは見出し要素、表セル、キャプション、凡例またはタイトル要素に表示されます。条件入力と検索結果では「／条件入力」「／検索結果」が付く場合も扱います。
- 時間割には「年度・学期」と隣接する「2026年度 第1学期」のような値があります。引き継ぎ年度と一致する場合に進みます。時間割は月〜土の列見出しと先頭の「1限」〜「7限」または「HT」行ラベルを持つ長方形の表を想定します。複数の表が表示される場合は、キャプションまたはタブパネルのラベルで学期を区別します。
- 学期タブは「第1学期」「第2学期」と表示される操作要素です。「追加」は対象セル内に一つだけ表示されるリンクです。登録済み開講番号は、既存の取り込みと同じ `div.tblDivNml` 内の `CallDetail` リンクに表示され、関数の開講番号引数とも一致するものを使います。「不許可となった科目」の別表は判定対象から外れます。
- 条件入力では「検索開始」のあるフォームが一つあり、各欄は `label` または隣接する表セルに「開講所属」「開講番号」「曜日」「時限」と表示されます。「曜日」「時限」は前画面のコマに対応する値が選択済みである必要があります。開講所属の「指示なし」が利用できる場合だけ選び、開講番号を入力します。
- 検索結果は「開講番号」「科目名」「選択」「優先度」の見出しを持つ表一つを想定します。開講番号が完全一致する行が一つで、その行の選択列にリンクが一つあれば枠で示します。リンクに対する利用者のクリックを受け取った後に、同学期の時間割で登録結果を確認します。スキップは一意の「戻る」がある画面で使えます。
- 失敗メッセージは、表示中の `role="alert"` または `aria-live="assertive"` にある既知の定型文だけ表示します。140文字を上限とし、氏名や学籍番号などを含められる自由記述は取り出しません。定型文が見つからなければ、学務画面で確認を促します。
- 非表示の要素、無効な操作要素、複数候補や解釈できない表では操作を止めます。リンクやフォームの遷移先を判定できる場合は同じ公式サーブレットに限ります。ページ構造やラベルが実環境と異なる場合は、アプリのメニューが無効になるか、入力補助が終了します。

## 合成画面で検証する

```sh
npm --prefix web_scripts ci
npm --prefix course_planner ci
npm --prefix web_scripts run build
npm --prefix web_scripts run check
node test/support/registration_assist_browser.mjs
flutter analyze lib test
flutter test
```

ブラウザーテストは Chrome の一時プロファイルを使い、全リクエストを捕捉して合成の画面に差し替えます。固定トークンの2学期分の遷移、開講番号の完全一致、登録期間外、選択・削除・優先度の操作制限を確認します。

# 学務から履修手帖に取り込む

MBG と履修手帖を同じ Google アカウントでログインすると、取得できた所属・学年、成績、区分別の既修得単位数、履修登録状況を自動で共有します。学務へのログイン確認後は12時間に1回までバックグラウンドで取得し、照会画面を開いたときも変更を共有します。データは Google ドライブのアプリ専用領域（appDataFolder）に平文で保存します。設定の「履修手帖と学務の照会結果を自動で共有」は初期状態でオンです。オフにすると自動共有を停止し、「共有した照会結果をGoogleから削除」で保存済みのデータを削除できます。下記のコピー操作も引き続き使えます。

アプリの縦三点「メニュー」→「履修手帖を開く」で `https://gakujo.terudoru.com/syllabus/` を外部ブラウザーで開きます。

学務にログインしていれば、照会画面を先に開いていなくても、任意の学務ページから「メニュー」→「学務の照会結果を履修手帖用にコピー」を選べます。MBG はログイン済みの画面と同一オリジンのフレームから「単位修得状況照会」「履修登録・登録状況照会」のメニューリンクを探し（リンクが見つからない場合は、単位修得状況は `_flowId=SIW0001300-flow`、履修登録状況は `_flowId=RSW0001000-flow` のポートレットフローへフォールバック）、バックグラウンドで読み取り専用の GET を行って取得できた項目をまとめます。個人情報のコピーを一度だけ確認すると、`MBGPLAN1.` 形式のトークンを項目ごとに改行区切りでクリップボードへコピーします（順序: 所属・学年（候補）、成績、区分別の既修得単位数、履修登録状況）。表示される「履修手帖を開く」からブラウザーに移り、設定 →「More Better Gakujo から貼り付け」で内容を確認して取り込みます。

バックグラウンド取得で一部の項目しか得られなかった場合は、現在表示中の照会画面もあわせて確認し、不足している項目を同じ確認ダイアログと一括コピーに含めます。バックグラウンド取得で項目が得られなかった場合や失敗した場合は、従来どおり表示中の照会画面から項目を選んでコピーする手順にフォールバックします。なお、実サイト上のメニューリンクの DOM 構造（特に「単位修得状況照会」）は実機未検証のため、初回利用時に意図どおり取得できるか確認してください。成績が自動で拾えない場合も、「単位修得状況照会」を手動で開いて再実行すれば、表示中の成績もまとめて（取得結果が空のときは従来フローで）取り込めます。

区分別の既修得単位数は、その区分と既修得単位の列が画面に表示された場合に取り込めます。帳票 PDF だけに表がある場合は、履修手帖のファイル取り込みを使います。「所属・学年（候補）」は学務の照会画面で「所属」と「学年」が隣接セルに表示される場合に読み取れます。所属だけが表示されている場合は学年を空欄にします。

時間割内の開講番号と許可表示、および「不許可となった科目」の別表を照合します。時間割のコマの背景色は開講形態を示します。学務への申請・確定は学務で本人が行います。[大学の履修登録手順書 9 ページ](https://www.niigata-u.ac.jp/wp-content/uploads/2020/03/risyuu_tejun.pdf#page=9)・[学務情報システム留学生向けマニュアル 6 ページ](https://www.niigata-u.ac.jp/wp-content/uploads/2025/03/J_studentweb_manual.pdf#page=7)

照会データの取得では、表示中の公式フレームとログインの世代を確認します。アカウントや画面が変わった場合は学務画面からやり直します。MBG は履修手帖を WebView に埋め込まず、学務の認証情報をブラウザーに渡しません。

## 合成データでの検証

リポジトリのルートで依存関係を準備して実行します。

```sh
npm --prefix web_scripts ci
npm --prefix course_planner ci
npm --prefix web_scripts run check
node test/support/course_planner_portal_browser.mjs
flutter test test/course_planner_handoff_test.dart test/gakujo_toolbar_copy_url_test.dart
```

ブラウザー検証は Chrome の一時プロファイルでリクエストを合成 HTML に差し替えます。ウィジェット検証は外部ブラウザーのランチャーをモックし、URL と外部起動設定を確認します。

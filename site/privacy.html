プライバシーポリシー

施行日：2026年11月6日

More Better Gakujo はオープンソースの非公式アプリです。運営者は開発者の GitHub ユーザー terudoru です。お問い合わせは GitHub Issues へお願いします。開発者はアプリ用のサーバーを運用していません。

Google データの利用

Google 機能は任意です。同期や Drive 保存に使うため、次の権限を求めます。

  • openid、email：接続中の Google アカウントを表示し、同期と Drive 保存の設定をそのアカウントに結び付けます。
  • https://www.googleapis.com/auth/drive.appdata：本人の Google ドライブ内にあるアプリ専用の非表示領域 appDataFolder で、暗号化した同期ファイルとバックアップを読み書きします。
  • https://www.googleapis.com/auth/drive.file：ダウンロードの Drive 保存をオンにしたときだけ追加で求めます。More Better Gakujo/科目名/ フォルダを作り、ダウンロードしたファイルをアップロードします。アプリが作成したファイルにアクセスし、フォルダの所有・共有・ゴミ箱の状態を確認します。同名ファイルのサイズ、MD5 などのメタデータを重複防止やアップロードの復旧に使います。保存後にフォルダが非公開でないと判明した場合、ファイルの削除を試みます。

同期対象は、連絡通知のスターの ID・件名・日時、お気に入り、設定、レポート下書き、通知済み締切のキーと日時です。スター以外は項目ごとに選べます。同期先のバックアップにはスターと有効にしたお気に入り、設定、通知済み締切が含まれます。同期ファイルとバックアップはアップロード前に端末で暗号化されます。鍵は端末外へ送信されず、利用者がペアリングコードを別の端末へ渡すときだけ端末間で共有されます。Drive には鍵 ID などの管理情報も保存します。ダウンロード保存のファイルはこの同期暗号化の対象ではありません。

Windows・macOS・Linux の Google 認証では、更新トークンを端末の安全な保存領域に保存し、アクセストークンはメモリで扱います。Android・iOS では Google Sign-In が認証を管理し、アプリはアクセストークンをメモリで扱います。トークンは Google の認証・API にのみ送ります。

共有と利用の制限

開発者は Google ユーザーデータを第三者に販売・譲渡せず、広告、分析、クラッシュ報告、AI・機械学習モデルの学習に使いません。開発者がデータを人手で読むことはありません。Google は機能の提供先としてデータを処理します。

More Better Gakujo による Google API から受け取った情報の利用および他のアプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。

接続の解除とデータの削除

  • アプリで Google からログアウトすると、トークンの取り消しと端末内の認証状態の削除を試みます。Android では再起動後などアカウントがメモリにない場合、取り消せなかったことを通知します。必要に応じて Google アカウントの接続設定 でもアクセスを解除してください。
  • 「同期データをリセット」は同期先の全端末の同期ファイル、同期先のバックアップと鍵ファイルを削除して新しい鍵を作ります。他の端末には新しいコードが必要です。Google ドライブの設定「アプリの管理」から非表示のアプリデータを削除することもできます。
  • Drive に保存したダウンロードは、Google ドライブで More Better Gakujo フォルダを手動で削除してください。
  • 「データをすべて削除」は同期を無効にし Google からログアウトします。WebView のレポート下書きと自動バックアップのファイルは削除されません。同期先のファイルや Drive に保存したダウンロードも別途削除してください。

その他のデータ

保存を選んだ学情のログイン ID・パスワードは端末の安全な保存領域に保存します。アプリのデータは端末内にも保存され、一部は平文の設定ファイルや WebView のローカルストレージに置かれます。任意の同期を有効にすると、選んだデータは上記の Google Drive または利用者が設定した WebDAV / S3 に送られます。アプリは学情と通信し、更新確認では GitHub に、授業暦の取得では新潟大学のサイトに接続します。外部リンク（AKIKO など）は利用者が選んだときに開きます。

Privacy policy

Effective: November 6, 2026

More Better Gakujo is an unofficial open-source app operated by its developer, GitHub user terudoru. Contact us through GitHub Issues. The developer does not operate an app server.

Google data we access and why

Google features are optional. The app requests:

  • openid and email to display the connected Google account and bind sync and Drive-save settings to that account.
  • https://www.googleapis.com/auth/drive.appdata to read and write encrypted sync files and backups in the app's hidden appDataFolder in your own Google Drive.
  • https://www.googleapis.com/auth/drive.file only when you enable saving downloads to Drive. The app creates More Better Gakujo/course name/ folders and uploads downloaded files. It accesses files it creates and checks folder ownership, sharing and trash status. It reads metadata including names, sizes and MD5 checksums to avoid duplicates and recover uploads. If a folder is found not to be private after upload, the app attempts to delete the file.

Sync includes starred announcement IDs, titles and timestamps; optionally, favorites, settings, report drafts, and keys and timestamps of notified deadlines. Sync backups include stars and enabled favorites, settings and notified deadlines. Sync files and backups are encrypted on the device before upload. Keys do not leave your devices except when you transfer a pairing code to another device. Management information including the key ID is also stored in Drive. Downloaded files saved to Drive are not covered by this sync encryption.

On Windows, macOS and Linux, the refresh token is stored in device secure storage and the access token is held in memory. On Android and iOS, Google Sign-In manages authentication and the app holds the access token in memory. Tokens are sent only to Google's authentication services and APIs.

Sharing and restrictions

The developer does not sell or transfer Google user data to third parties, use it for advertising, analytics, crash reporting, or AI/ML model training, or read it manually. Google processes data to provide its services.

More Better Gakujo's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Revoke access and delete data

  • Signing out in the app attempts to revoke authorization and clear local authentication state. On Android, after a restart or when the account is not in memory, revocation may not be possible and the app reports this. You can also revoke access at Google Account connections.
  • Resetting sync deletes all devices' sync files, sync backups and the key file from the sync destination and creates a new key; other devices need the new code. You can also delete hidden app data in Google Drive settings under Manage apps.
  • Delete the More Better Gakujo folder manually in Drive to remove uploaded downloads.
  • “Delete all data” disables sync and signs out of Google. It does not delete report drafts in WebView storage or automatic backup files. Delete sync data in Drive and uploaded downloads separately.

Other data

If you choose to save your Gakujo login ID and password, they are stored in device secure storage. App data is also stored locally; some is kept in a plaintext settings file or WebView local storage. If optional sync is enabled, selected data is sent to Google Drive or your configured WebDAV / S3 server as described above. The app communicates with Gakujo, connects to GitHub to check for updates and to Niigata University's site to retrieve the academic calendar. External links such as AKIKO open when you choose them.

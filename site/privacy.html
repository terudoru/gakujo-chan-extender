プライバシーポリシー

施行日：2026年11月18日

More Better Gakujo はオープンソースの非公式アプリです。運営者は開発者の GitHub ユーザー terudoru です。お問い合わせ・報告データの削除依頼は gakujo@terudoru.com へお願いします。不具合・要望は GitHub Issues でも受け付けます。アプリは、利用者が不具合や要望を送信したときだけ、その内容を開発者に送ります。詳しくは下記の「不具合・要望の報告」を見てください。

Google データの利用

Google の機能は任意です。同期やダウンロードの Google ドライブ保存のために、次の権限を求めます。

  • openid、email：接続中の Google アカウントを表示し、同期と Google ドライブ保存の設定をそのアカウントに結び付けます。
  • https://www.googleapis.com/auth/drive.appdata：本人の Google ドライブ内にあるアプリ専用の非表示領域 appDataFolder で、暗号化した同期ファイルとバックアップを読み書きします。
  • https://www.googleapis.com/auth/drive.file：ダウンロードの Google ドライブ保存をオンにしたときだけ追加で求めます。既定の More Better Gakujo フォルダ、または利用者が選んだ非共有フォルダに、ダウンロードしたファイルを科目別に保存します。アプリが作成したファイルと、保存先として利用者がアクセスを許可したフォルダにアクセスします。フォルダについては、所有者、共有の状態、ゴミ箱に入っているかを確認します。同名ファイルのサイズや MD5 などのメタデータは、重複を防ぐためとアップロードを復旧するために使います。保存後にフォルダが非公開でないと判明した場合は、ファイルの削除を試みます。

同期の対象は次のとおりです。スター以外は項目ごとに選べます。

  • 連絡通知のスターの ID・件名・日時
  • お気に入り
  • 設定
  • レポート下書き
  • 通知済み締切のキーと日時

同期先のバックアップには、スターと、有効にしたお気に入り・設定・通知済み締切が含まれます。

同期ファイルとバックアップは、アップロード前に端末で暗号化されます。Google ドライブ同期では鍵も同じアカウントのアプリ専用領域に保存するため、Google や、アカウントとこのアプリの Drive 権限にアクセスできる人は内容を読めます。Google ドライブに保存したダウンロードファイルは、この同期用の暗号化の対象ではありません。

Windows・macOS・Linux では、Google の認証に使う更新トークンを端末の安全な保存領域に保存し、アクセストークンはメモリで扱います。Android・iOS では Google Sign-In が認証を管理し、アプリはアクセストークンをメモリで扱います。トークンの送信先は、Google の認証サービスと API だけです。

共有と利用の制限

開発者は Google ユーザーデータを第三者に販売も譲渡もしません。広告、分析、クラッシュ報告、AI・機械学習モデルの学習にも使いません。開発者が自分でデータを読むこともありません。Google は自社のサービスを提供するためにデータを処理します。

More Better Gakujo は、Google API から受け取った情報の利用と他のアプリへの転送について、Limited Use 要件を含む Google API Services User Data Policy に従います。

接続の解除とデータの削除

  • アプリで Google からログアウトすると、トークンの取り消しと、端末内の認証状態の削除を試みます。必要に応じて Google アカウントの接続設定 でもアクセスを解除してください。
  • 「同期データをリセット」は、全端末の同期ファイル、バックアップ、鍵ファイルを同期先から削除し、新しい鍵を作ります。Google ドライブでは他の端末も新しい鍵を自動的に取得します。Google ドライブの設定「アプリの管理」から、非表示のアプリデータを削除することもできます。
  • Google ドライブに保存したダウンロードファイルを消すには、Google ドライブで保存先の科目フォルダを開き、対象のファイルを削除してください。
  • 「データをすべて削除」は、同期を無効にし、Google からログアウトします。WebView（アプリ内でウェブページを表示する部品）に保存したレポート下書きと、自動バックアップのファイルは削除されません。同期先のファイルや Google ドライブに保存したダウンロードファイルも、別途削除してください。

Google 以外のデータと接続先

保存を選んだ場合、学情のログイン ID とパスワードは端末の安全な保存領域に保存します。アプリのデータは端末内にも保存され、一部は平文の設定ファイルや WebView のローカルストレージに置かれます。任意の同期を有効にすると、選んだデータは上記の Google ドライブに送られます。アプリは学情と通信し、更新確認では GitHub に、授業暦の取得では新潟大学のサイトに接続します。外部リンク（AKIKO など）は利用者が選んだときに開きます。

不具合・要望の報告

報告の受付は公開後に利用できます。報告は、アプリの「アプリから報告する」か、ブラウザーの報告ページ（gakujo.terudoru.com/report/）から送れます。GitHub や Google のアカウントは不要です。受付には Google Apps Script を使い、報告は開発者が管理する Google のスプレッドシートに非公開で保存します。Google がこの処理を行います。

保存するのは、報告の種類（バグ報告、機能追加の要望、既存機能の改善要望、その他）、件名、内容、任意の「問題が起きるまでの手順」と「本来どうなってほしかったか」、アプリのバージョン、OS、受付日時、受付番号、二重登録を防ぐための送信ごとのランダムな識別子です。アプリからバグ報告を送る場合は、軽量版の診断情報（アプリの設定の状態、保存している件数、端末の種類など）も一緒に送ります。送る内容は送信前に画面で確認でき、付けずに送ることもできます。ログイン情報、閲覧した URL、履歴、学情の画面の内容は送りません。IP アドレスは開発者側では受け取らず、保存もしません。

開発者が報告を確認し、件名、内容、手順、本来どうなってほしかったか、アプリのバージョン、OS を公開の GitHub Issue に載せることがあります。診断情報、受付日時、受付番号、識別子は公開しません。報告は受付から180日を過ぎると、毎日の処理でスプレッドシートから削除します。受付番号を添えてお問い合わせいただければ、それより前に削除します。スプレッドシートの変更履歴など Google 側に残る情報は、Google のサービスの仕組みに従って扱われます。氏名、学籍番号、ログイン情報などは入力しないでください。

変更はこのページと リポジトリ で公開します。

Privacy policy

Effective: November 18, 2026

More Better Gakujo is an unofficial open-source app operated by its developer, GitHub user terudoru. For inquiries or requests to delete a report, email gakujo@terudoru.com. You can also submit bugs and feature requests through GitHub Issues. The app sends information to the developer only when you submit a bug report or feature request, as described under “Bug reports and feature requests” below.

Google data we access and why

Google features are optional. The app requests:

  • openid and email to display the connected Google account and bind sync and Drive-save settings to that account.
  • https://www.googleapis.com/auth/drive.appdata to read and write encrypted sync files and backups in the app's hidden appDataFolder in your own Google Drive.
  • https://www.googleapis.com/auth/drive.file only when you enable saving downloads to Drive. The app saves downloads by course under More Better Gakujo or a private folder you select. It accesses files it creates and folders you authorize as save locations. It checks folder ownership, sharing and trash status. It reads metadata including names, sizes and MD5 checksums to avoid duplicates and recover uploads. If a folder is found not to be private after upload, the app attempts to delete the file.

Sync includes starred announcement IDs, titles and timestamps; optionally, favorites, settings, report drafts, and keys and timestamps of notified deadlines. Sync backups include stars and enabled favorites, settings and notified deadlines. Sync files and backups are encrypted on the device before upload. For Google Drive sync, the key is stored in the same account’s app-only area, so Google and anyone with access to the account and this app’s Drive permission could read the content. Downloaded files saved to Drive are not covered by this sync encryption.

On Windows, macOS and Linux, the refresh token is stored in device secure storage and the access token is held in memory. On Android and iOS, Google Sign-In manages authentication and the app holds the access token in memory. Tokens are sent only to Google's authentication services and APIs.

Sharing and restrictions

The developer does not sell or transfer Google user data to third parties, use it for advertising, analytics, crash reporting, or AI/ML model training, or read it manually. Google processes data to provide its services.

More Better Gakujo's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

Revoke access and delete data

  • Signing out in the app attempts to revoke authorization and clear local authentication state. You can also revoke access at Google Account connections.
  • Resetting sync deletes all devices' sync files, sync backups and the key file from the sync destination and creates a new key; other devices automatically obtain the new key for Google Drive. You can also delete hidden app data in Google Drive settings under Manage apps.
  • To remove uploaded downloads, open the course folder in your chosen Drive location and delete the files you want to remove.
  • “Delete all data” disables sync and signs out of Google. It does not delete report drafts in WebView storage or automatic backup files. Delete sync data in Drive and uploaded downloads separately.

Other data

If you choose to save your Gakujo login ID and password, they are stored in device secure storage. App data is also stored locally; some is kept in a plaintext settings file or WebView local storage. If optional sync is enabled, selected data is sent to Google Drive as described above. The app communicates with Gakujo, connects to GitHub to check for updates and to Niigata University's site to retrieve the academic calendar. External links such as AKIKO open when you choose them.

Bug reports and feature requests

Reporting will be available after deployment. You can send a report from “アプリから報告する” in the app or from the report page in a browser (gakujo.terudoru.com/report/). No GitHub or Google account is needed. Reports are received by Google Apps Script and stored privately in a Google spreadsheet managed by the developer; Google processes this data.

We store the report type (bug report, feature request, improvement request or other), title, description, optional steps to reproduce and expected behavior, app version, operating system, submission time, receipt number and a random per-submission identifier used to prevent duplicates. Bug reports sent from the app also include a lightweight diagnostic (the state of app settings, counts of saved items and the device type). You can review it before sending and choose to send without it. Login credentials, visited URLs, history and Gakujo page content are not sent. The developer does not receive or store IP addresses.

The developer reviews reports and may include the title, description, steps, expected behavior, app version and operating system in a public GitHub Issue. Diagnostics, submission time, receipt numbers and identifiers are never published. Reports are deleted from the spreadsheet by a daily job after 180 days. You can request earlier deletion by contacting the developer with your receipt number. Information kept by Google, such as spreadsheet version history, is handled under Google’s own service practices. Do not enter names, student IDs or login credentials.

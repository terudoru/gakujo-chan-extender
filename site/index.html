More Better Gakujo

新潟大学の学務情報システム（学情）をアプリの中で開き、ログイン、2段階認証、資料の保存を楽にする非公式アプリです。Android、iOS/iPadOS、Windows、macOS、Linux に対応します。新潟大学とも、元のブラウザ拡張の作者とも関係ありません。オープンソースとして terudoru が開発しています。

主な機能

  • 学情へのログインと2段階認証の自動入力
  • 資料のダウンロード、プレビュー、保存
  • 連絡通知のスター、お気に入り、レポート下書き
  • 任意の端末間同期：Google ドライブで同期（drive.appdata）または WebDAV / S3
  • 任意のダウンロードの Google ドライブ保存（drive.file）

Google の機能は v0.70.6 の次のリリースに含める予定です。入手方法や対応状況は README と Releases を確認してください。

More Better Gakujo

An unofficial app that opens Niigata University's academic information system, Gakujo, and makes login, two-factor authentication, and saving course materials easier. It supports Android, iOS/iPadOS, Windows, macOS, and Linux. It is independent of Niigata University and the author of the original browser extension. The open-source app is developed by terudoru.

Features

  • Login and automatic two-factor authentication entry
  • Download, preview, and save materials
  • Star announcements, save favorites, and keep report drafts
  • Optional device sync via Google Drive (drive.appdata) or WebDAV / S3
  • Optional saving of downloads to Google Drive (drive.file)

The Google features are planned for the release after v0.70.6. See the repository and README, releases, and privacy policy.

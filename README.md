# More Better Gakujo

More Better Gakujo は、新潟大学の学務情報システム（学情）をアプリの中で開き、ログイン、2段階認証、資料の保存を楽にする非公式アプリです。Android、iOS/iPadOS、Windows、macOS、Linux に対応します。新潟大学とも、元のブラウザ拡張の作者とも関係ありません。

## まず覚えること

1. 最新版は [GitHub Releases](https://github.com/terudoru/gakujo-chan-extender/releases) から入手する
2. 2段階認証を自動入力するには、6桁のコードではなく Base32 形式の秘密鍵を設定画面に保存する
3. 資料の保存方法は、設定の保存モードで選ぶ
4. うまく動かないときは、下の「困ったとき」の表を見る

初めて使うときは「入手とインストール」と「初回設定」を読んでください。ほかの節は、必要になったときに開けば足ります。開発やリリース作業の資料は、末尾の「関連資料」にあります。

## 入手とインストール

v0.70.6 の GitHub Releases には、Android、Windows、macOS の配布ファイルがあります。iOS/iPadOS 版は、v0.70.6 には含まれていません。SideStore で配布している最新の iOS 版は 0.70.0 です。

### Android

- `MoreBetterGakujo-vX.Y.Z.apk` をダウンロードしてインストールする（64ビット ARM〔arm64-v8a〕の Android 端末向け）
- 端末の設定によっては、「提供元不明のアプリ」の許可が必要
- v0.68.0 以前とは署名が違うため、旧版の上から更新できない。旧版をアンインストールしてから入れる
- アンインストールすると、アプリ内のデータは消える

### Windows

- `MoreBetterGakujo-vX.Y.Z.exe` はインストーラー、`MoreBetterGakujo-vX.Y.Z.zip` はインストール不要のポータブル版
- Microsoft Edge WebView2 Runtime が必要。Windows 10/11 には通常入っている。入っていなければ Microsoft から入手する

### macOS

- `MoreBetterGakujo-vX.Y.Z.dmg` を開き、アプリを「アプリケーション」フォルダにコピーする
- macOS 10.15 以降が必要
- Developer ID で署名していないので、初回は macOS の設定の「プライバシーとセキュリティ」で「このまま開く」を選ぶ

### Linux

- x64 の Ubuntu 22.04 以降 / Debian 12 以降を対象とする。`MoreBetterGakujo-vX.Y.Z-linux-amd64.deb` は `sudo apt install ./MoreBetterGakujo-vX.Y.Z-linux-amd64.deb` を実行して入れる
- `MoreBetterGakujo-vX.Y.Z-linux-x64.tar.gz` は展開し、展開したフォルダの `morebettergakujo_flutter` を起動する。実行には `libgtk-3-0`、`libwebkit2gtk-4.1-0`、`libsecret-1-0` が必要
- Fedora と Arch Linux では tar.gz を使う。先に必要なライブラリを入れておく（Fedora: `sudo dnf install gtk3 webkit2gtk4.1 libsecret`、Arch: `sudo pacman -S gtk3 webkit2gtk-4.1 libsecret`）
- パスワードの保存には Secret Service（GNOME Keyring / KWallet など）が必要
- Linux では QR コードの読み取りは使えない

### iOS/iPadOS

App Store では配布していません。利用者が自分の Apple Account で署名して入れる、技術者向けの配布です。iOS/iPadOS 14 以降が必要です。

- Mac か PC がある場合は、IPA を Sideloadly にドロップして署名する。Sideloadly の自動更新デーモンを有効にしておく
- Mac がない場合は、SideStore の初期設定を済ませたうえで、次の source を追加してインストールする。GitHub Releases の IPA を直接ダウンロードして SideStore で開いてもよい

```text
https://raw.githubusercontent.com/terudoru/gakujo-chan-extender/main/distribution/altstore-source.json
```

入れる前に、次の点を確かめてください。

- 無料の Apple Account では、通常7日以内に署名の更新が必要
- 無料の Apple Account では、同時に有効にできるサイドロードアプリの数に上限がある
- Apple やサイドロードツールの仕様が変わると、インストールや更新ができなくなることがある
- Apple Account のパスワード、証明書、プロビジョニングプロファイルを他人と共有しない

## できること

元のブラウザ拡張にあった機能:

- 学情がタイムアウトするまでの残り時間を自動で延長する
- レポートを提出期間・タイトル・開講番号で並べ替える。一時保存のレポートを青字にする
- 成績を得点・開講番号・No. で並べ替え、GPA を表示する
- 連絡通知を、上から指定した件数だけ既読にする
- 2段階認証のコードを自動入力して、次のページに進む

このアプリで加えた機能:

- ログイン ID とパスワードの自動入力
- ダウンロードした資料を、科目ごとのフォルダに自動で仕分けて保存する
- ダウンロード履歴と、授業ごとの資料一覧
- 連絡通知のスターと、キーワードによる除外
- 成績・レポート・連絡通知の更新検知と、提出期限の抽出・OS 通知
- レポート本文の下書きの自動保存
- 授業予定をカレンダーに追加する（「授業カレンダー連携」の節）
- スターや設定を複数の端末で共有する（「端末間の同期」の節）。v0.70.6 には含まれていない
- 5MB を超える添付ファイルを、提出前に自動で圧縮する。JPEG/PNG/WebP、PDF、Word/PowerPoint/Excel に対応する。PDF は 64 MiB 以下が対象で、文字や OCR を残したまま画像の画質を段階的に下げる。圧縮できないときは元のファイルのまま提出する
- 提出前に、選んだ PDF や画像をプレビューする。PDF は連続スクロール、ページ移動、拡大・縮小、文字検索に対応する
- 提出済みファイルを、保存せずにプレビューする。PDF、JPEG/PNG/WebP、テキスト、主な音声・動画に対応する。Word/Excel/PowerPoint は本文だけを表示し、書式や画像は再現しない
- 設定・履歴・お気に入りなどのバックアップと復元
- GitHub Releases の新しい版の確認
- マウスの戻る・進むボタンでのページ移動（Windows/macOS）

各機能は、設定の機能オン/オフで個別に止められます。

## 初回設定

初回起動時のセットアップで、表示モード、保存モード、保存先、使う機能をまとめて設定します。あとから変えるときは、右上の設定を開きます。

### 2段階認証の秘密鍵

- 設定画面に、Base32 形式の長い秘密鍵を保存する。6桁の認証コードを保存しても自動入力されない
- 秘密鍵の取り出し方は、[元プロジェクトの説明](https://github.com/koji-genba/gakujo-chan-extender#2段階認証自動入力)を見る
- 秘密鍵を控えるなら、暗号化されたパスワードマネージャーに入れる。共有メモや暗号化していないファイルには書かない

### 保存モードと保存先

保存モードは次の3つから選びます。

- 自動仕分けして指定フォルダに保存
- 自動仕分けせず指定フォルダに保存
- 自動仕分けせず毎回保存場所を選ぶ

自動仕分けでは、ページ内の「科目名」欄やファイル名から科目名を判定し、指定フォルダの下に科目名のフォルダを作って保存します。判定できないときは「未分類」フォルダに入ります。

- iOS/iPadOS では、iCloud Drive のフォルダを保存先にすれば自動仕分けを使える
- Google Drive は、iOS/iPadOS の「ファイル」アプリでフォルダを保存先に指定できないことがある。その場合は「自動仕分けせず毎回保存場所を選ぶ」を使う
- Windows では、転送先が変わるダウンロードを安全のためブロックする。通知のリンクを開くときも確認画面が出る

### 表示モード

学情のモバイル版ページとデスクトップ版ページのどちらを開くかを選べます。

## 授業カレンダー連携

学情の授業予定を、カレンダーに追加・更新します。設定の「Googleスケジュール連携」で、追加方法、ターム、授業のない日の扱い、追加先のカレンダー名を確かめてから実行します。

### 追加方法

| 方法 | 動き |
|---|---|
| 自動で選ぶ | Android・iOS・macOS では OS のカレンダーに直接追加する。Windows には安全に書き込める共通のカレンダー API がないので、学情の Google 連携を開き、見つからなければ `.ics` ファイルを書き出して既定のカレンダーアプリで開く |
| OSカレンダーへ直接追加 | ターム期間、授業のない日、振替日を反映し、まとめて削除もできる。予定には `MBG_UID:` で始まる識別子を入れておき、再実行すると、対象ターム内のこのアプリが入れた予定を消してから入れ直すので、予定は重複しない |
| 本家Google連携を開く | 学情側の「Googleスケジュール連携」を開く |
| iCalendarファイルを書き出す | `more-better-gakujo-classes.ics` を書き出す。各授業の `UID` は年度、ターム、授業名、曜日、時限、教室から作るので、書き出し直しても同じ予定として扱われやすい。それでも何度も手動で取り込むと、カレンダーアプリによっては予定が重複する |

予定のタイトル、場所、説明は、学情の Google カレンダー連携のリンクに入っている内容だけを使います。学情側の連携予定がページに見つからないときは、アプリが推測で授業を作らず、学情の「Googleスケジュール連携」を開きます。

### ターム

- 初期設定では、新潟大学の公式授業暦 PDF から、今日が属するタームを自動で判定する
- タームの間の休みには次のタームを、第4ターム後の春休みには翌年度のタームを対象にする
- 授業のない日は、設定で有効にしていれば予定から外す
- 授業振替日（例：「4/27 水曜日授業振替」）には、振替先の曜日の授業を入れる
- 公式授業暦 PDF を取得できないときは、アプリに入っている令和8年度・令和9年度の授業暦を使う
- ページから読み取った期間や、手で入力した期間を使う設定にもできる

### `.ics` を URL で購読する

書き出した `.ics` を決まった URL に置いて購読すると、手動で取り込むより重複しにくくなります。毎回同じ場所のファイルを上書きしてください。

- GitHub Gist：ファイル名を `more-better-gakujo-classes.ics` にして内容を貼り、Raw URL を購読する。secret の Gist でも、URL を知っている人は中身を見られる
- GitHub Pages：`calendar/more-better-gakujo-classes.ics` に置いて公開 URL を購読する。中身は誰でも見られる

授業名や教室が入るので、URL を共有する範囲に注意してください。購読の追加先は次のとおりです。反映される間隔はカレンダーアプリによって違います。

| カレンダー | 追加する場所 |
|---|---|
| Google カレンダー | 設定の「カレンダーを追加」→「URLで追加」 |
| Apple カレンダー（macOS） | 「ファイル」→「新規照会カレンダー」 |
| Apple カレンダー（iOS/iPadOS） | 設定アプリでカレンダーのアカウントを追加する |
| Outlook | 「カレンダーを追加」→「Webから追加」 |

## 端末間の同期

この機能は main ブランチにあり、v0.70.6 には含まれていません。

設定の「スターの端末間同期」で、次の項目を同じ人の複数の端末で共有できます。開発者側ではサーバーを用意しません。

- 連絡通知のスター。同期するのは ID と件名だけで、本文は端末の中にだけ残り、通知を開いたときに読み込み直す
- お気に入り、設定、レポート下書き、通知済みの締切（項目ごとにオン/オフできる）

同期先は次から選びます。

- Google ドライブ：Google アカウントだけで使える。2台目以降は、1台目の「別の端末を追加」に出る QR コードかペアリングコードで参加する。このボタンは、Google の OAuth クライアント ID を組み込んだビルドにだけ出る。いまの GitHub Actions のリリースビルドには組み込んでいない
- WebDAV または S3 互換ストレージ：詳細設定から、自分のサーバーの接続情報とパスフレーズを入れる

使う前に、次の点を確かめてください。

- 同期するには、設定の「ログイン」でログイン ID を保存しておく必要がある。ログイン ID が設定したときと変わると、同期は止まる
- 共用の端末では同期を設定しない。同期で受け取った内容は、その端末を使うほかの人からも見える
- ペアリングコードやパスフレーズを知っている人は、同期データを読める。忘れたときは同期データをリセットしてやり直す（端末の中のスターは残る）
- Google ドライブで同期するなら、全端末をなくしたときに備えて、「別の端末を追加」のコードを安全な場所に控えておく

任意で、ダウンロードした資料を Google ドライブの `More Better Gakujo/科目名/` にも保存できます。仕組みの詳細は [docs/star-sync.md](docs/star-sync.md) にあります。

## バックアップ

- 自動バックアップは、設定・履歴・お気に入りなどを定期的にローカルの JSON に保存する。スター付きの通知は含めない
- すでにある自動バックアップのファイルは、アプリが削除しない
- スター付きの通知も残したいときは、手動でバックアップを作る。保存先と共有先に注意する
- バックアップにはログイン情報と2段階認証の秘密鍵を含めない
- バックアップから復元したダウンロードの失敗履歴は、再送できない。元のページからダウンロードし直す

## 困ったとき

| 症状 | 直し方 |
|---|---|
| 2段階認証が自動入力されない | 保存したのが6桁のコードではなく、Base32 形式の秘密鍵かを確かめる。学情の画面が変わると、自動入力できなくなることがある |
| 資料が「未分類」フォルダに入る | 科目名の判定はまだ実装の途中で、ファイル名に科目名があっても、形式によっては判定できない。ダウンロードしたページに科目名が出ているかを確かめ、直らなければ、ページ、ファイル名、本来の科目名を添えて報告する |
| Android で APK を上書き更新できない | 署名が違う APK は上から入れられない。古いアプリをアンインストールしてから入れる（アプリ内のデータは消える） |
| macOS でアプリを開けない | 「プライバシーとセキュリティ」で「このまま開く」を選ぶ |
| Windows で画面が表示されない | Microsoft Edge WebView2 Runtime を入れる |
| iOS でアプリが起動しなくなった | 署名の期限（無料の Apple Account では通常7日）が切れていないかを確かめ、Sideloadly か SideStore で署名し直す |

不具合は、設定で作れる診断情報かエラー報告パッケージを添えて、[GitHub Issues](https://github.com/terudoru/gakujo-chan-extender/issues) に報告してください。

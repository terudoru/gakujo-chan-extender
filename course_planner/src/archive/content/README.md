# 2026年度の授業比較データ

授業カードと詳細ダイアログには `SyllabusContent.jsx` の `<SyllabusContent course={course} year={year} />` を置く。名前付き・デフォルトのどちらでもインポートできる。`course` に必要な値は `department` と `code` で、読み上げ用の科目名には `title` を使う。`course.year` を持つ授業は `year` を省略できる。年度が一致しない場合は未収録と表示する。

2026年11月19日、全学部・全学共通の学部カタログ4,347件を、ログイン不要の個別シラバスの開講学期・開講番号と照合した。日本語版は4,328件、英語版は19件。比較項目を収録した授業は3,359件で、残る988件では確認先の個別ページを表示する。11個の開講所属別ファイルは合計402,959バイト。画面を開いた授業の所属分を一度だけ同一サイトから読み込む。

「コミュニケーション論I」は筆記試験75%、授業討論への参加25%。「エンジニアのためのデータサイエンス入門」は課題レポートによる評価と原則対面の記載がある。「英語基礎 L」は比較項目が未収録。言語は本文中の明示的な記載を採り、ページの表示言語や科目名からの推測はしない。[コミュニケーション論I](https://syllabus.niigata-u.ac.jp/syllabusHtml/2026/08/08_260DS217_ja_JP.html)／[エンジニアのためのデータサイエンス入門](https://syllabus.niigata-u.ac.jp/syllabusHtml/2026/84/84_261G3008_ja_JP.html)／[英語基礎 L](https://syllabus.niigata-u.ac.jp/syllabusHtml/2026/84/84_261G7011_ja_JP.html)

## 分野と科目区分の出典

個別ページの「分野」はカタログに既存の補正を適用した値と全4,347件で一致した。`field-evidence-2026.json` は開講所属・開講番号・分野の組を保持し、`currentOffering` が検証済みの組に個別URLを付ける。科目区分は4,314件で大学の一覧表の該当ページを示し、一覧表にページがない33件では個別ページの記載と一致した。[2026年度の科目一覧表](https://www.iess.niigata-u.ac.jp/acpb/upload/20260327161315092692700.pdf)

科目区分が両資料で異なる5件は、登録済みの一覧表の区分を維持した。`260DS217`・`260DS318`・`260DS421` は一覧表で英語、個別ページで医歯学。`260M1244`・`260M1409` は一覧表で医歯学、個別ページで英語。[一覧表13ページ](https://www.iess.niigata-u.ac.jp/acpb/upload/20260327161315092692700.pdf#page=13)／[一覧表126ページ](https://www.iess.niigata-u.ac.jp/acpb/upload/20260327161315092692700.pdf#page=126)／[一覧表127ページ](https://www.iess.niigata-u.ac.jp/acpb/upload/20260327161315092692700.pdf#page=127)

## 再生成と確認

`course_planner` で `python -X utf8 tools/archive_content.py PATH_TO_HTML_CACHE` を実行する。公開カタログの開講番号に対応する保存済みHTMLを優先し、不足分のみ大学の個別ページから取得する。キャッシュを更新する際は空のディレクトリを指定する。抽出と収録範囲は `python -X utf8 test/archive_content_test.py`、分野出典は `npm test`、配信用ビルドの画面と再試行は `node test/archive-content-browser.mjs` で確認できる。

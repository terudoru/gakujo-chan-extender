# Embedded PDF viewer

This Flutter Web application adapts the viewer example from [pdfrx 2.10.1](https://github.com/espresso3389/pdfrx) (MIT). The application embeds the generated files under `assets/pdf_preview/web`; it serves those static files on a capability-protected loopback address and sends the selected PDF to a sandboxed frame in memory. The viewer does not open arbitrary URLs or persist document bytes.

The upstream 2.10.1 worker is patched by `pdfium_worker.patch`: it loads bundled fallback fonts without persistent storage, bounds page and render sizes and the WebAssembly heap, and supports the pinned PDFium binary. `pdfium_client.patch` terminates the worker when its preview page closes. The patches are tied to the exact upstream hashes and require review when updating pdfrx. They do not bound the entire browser process.

To rebuild, use Flutter 3.47.8, run `flutter pub get` here, download the `pdfium-wasm.tgz` asset from [PDFium 158.0.8125.0](https://github.com/bblanchon/pdfium-binaries/releases/tag/chromium%2F8125), and verify the archive SHA-256 `77db4ef8c9ab0ecef2af659fe7d407279a0ebacff4cfcc1b3cc28160be2abfbd`. Extract its `lib/pdfium.wasm` and run `python build_viewer.py --pdfium-wasm PATH`; the script checks the binary and worker hashes before generating the bundled files. Do not commit a binary from an unverified archive. Review PDFium security updates when changing this pin.

The fallback fonts are Noto Sans CJK and GNU Unifont 18.0.01. `MBGPreviewUI.otf` is a renamed subset of Noto Sans CJK used only for interface labels, reducing the memory needed to display the controls. Regenerate it with `subset_ui_font.py` and fontTools 4.60.1, passing the Japanese localization Dart files from the `material_ui` and `cupertino_ui` versions in the lockfile. Its character set is derived from the viewer source and those localizations, so regenerate it after adding labels. Their licenses and the PDFium third-party notices are in `licenses/`. Fallback coverage does not guarantee that every document with missing fonts preserves its intended glyphs or shaping; embedded fonts remain preferable.
